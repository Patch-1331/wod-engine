# ADR 0002: Referencing CrossFit benchmark WOD names

**Status:** Accepted

## Context

The seed WOD library includes well-known community benchmark names
("Cindy," "Angie") and a hero-WOD-inspired entry ("Murph, Home Cap").
CrossFit is a registered trademark of CrossFit, Inc.

## Decision

Use the real community names for personal reference. Never use "CrossFit"
itself in the app's name, branding, or marketing, and never imply
affiliation with or endorsement by CrossFit, Inc.

## Reasoning

The individual benchmark names function as shared community vocabulary,
not as CrossFit Inc.'s trademark in commerce — established non-affiliated
apps (BTWB, SugarWOD, WodWell) reference them openly. The actual risk
surface is the word "CrossFit" itself, which the company actively
defends. This is a practice observation, not legal advice; if this app is
ever seriously commercialized, get a real legal opinion before that
launch.
